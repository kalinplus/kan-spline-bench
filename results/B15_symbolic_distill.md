# B15：KAN 符号蒸馏 — 158 条可读公式 + 重训第二层，IC 保留 97.2%

分析对象：B1 主 KAN（`[158,24,1]`，grid 5 / order 3 / ±3）。把 B4 已 snap 的 **158 个特征最强边
符号公式**（每个特征恰好一条边，冻结不再训练）作为第一层，替换掉的不仅是可读性诉求——原来整层
样条参数（158×24 条边）都被替换成 158 条闭式函数。只重训第二层（24→1 的同一
KANLayer），报告相对原 KAN 的 RankIC 保留比例。脚本：`scripts/run_b15_symbolic_distill.py`
（本仓库 feature/b15-symbolic-distill 分支），产物：`common/runs/kan/symbolic-distill/`。

**一句话结论**：把第一层压成 158 条人能读懂的公式（`0.600·sigmoid(1.557x−2.643)−0.056`
这种形式）后，测试集 RankIC 只掉 **2.8%**（0.02643 → 0.02570，保留 **97.2%**）。KAN 论文
「可解释性与精度可以兼得」的承诺在**排序层**兑现了；但组合层（多空收益、分层单调性）只保住约
一半（见第 3 节），所以完整表述应为「排序几乎无损、组合层有代价」。

## 0. 方法与口径

- **第一层（冻结，非训练）**：对 158 个特征各取 B4 判定的最强边（边范数 L1 口径），其函数为
  `φ(x) = a·f(b·x+c) + d`，`f ∈ {x, x², x³, |x|, sgn·log(1+|x|), sin, sigmoid, tanh}`
  （与 B4 `symbolic_snap_edges.csv` 同一候选族与拟合口径），参数直接读自 B4 产物，不重新拟合。
  158 条公式按 `strongest_hidden` 汇入 24 个隐藏节点（每节点 1–17 条入边，24 个节点全部被用到）。
  第一层以 buffer 形式注册——**0 个可训练参数**。
- **第二层（重训）**：与原 [158,24,1] KAN 的第二层完全同构（KANLayer 24→1，grid 5/order 3）。
  重训后的可训练参数 = 24 条边 × 10 = **240**（对照整模型为 38,160）。
- **paired 对照**：同一脚本、同一 seed(42)、同一 `run_b1.train_torch` 路径训练一次**原样条 KAN**
  （第一层可训）。两个模型唯一的差异 = 第一层是冻结的符号公式还是可训样条。
- **选择与评分纪律**：early stop / 模型选择只看 valid；test 集每个模型**只评分一次**，未基于
  test 做任何选择。
- **训练配置**：照抄 `run_b1.py`（AdamW lr 1e-3 / wd 1e-4 / batch 4096 / max 200 epoch /
  patience 15，CUDA，seed 42）；未调任何新超参。

## 1. 核心结果：IC 保留率

| 分子 / 分母 | 数值 |
|---|---|
| test RankIC（蒸馏，158 公式冻结第一层） | 0.025696 |
| test RankIC（paired 对照，第一层可训） | 0.026425 |
| **保留率（vs paired 对照）** | **97.24%** |
| test RankIC（B1 主表 KAN，外部参考） | 0.026425 |
| 保留率（vs B1 参考） | 97.24% |

关于两个分母的关系：**主分母是本次同脚本跑出的 paired 对照**（同 seed、同代码路径、唯一差异
是第一层），它是干净的因果对照。它同时几乎完美复现了 B1 主表的 KAN（test RankIC
0.026425210 vs B1 0.026425067，差 1.4e-7；valid 0.02775 @ epoch 5 与 B1 日志逐点一致），
所以两个分母给出同一个 97.2%。B1 参考只作外部交叉印证，不作为主口径。

## 3. 回测层对比（验收 #6）

### 3.1 口径定义

**回测组合指标**（`metrics.json` 的 `backtest` 字段，来自 `run_b1.evaluate_dump`，两个模型同一份
代码）：信号为逐日截面预测，`TopkDropoutStrategy(topk=30, n_drop=1)`，`deal_price=close`，
`limit_threshold=0.095`，`trade_unit=100`，`min_cost=5`，成本 `open 0.05% / close 0.15%`，基准
SH000300，区间 = test 2023-01-03 ~ 2026-07-23（860 个交易日）。其中：

- `annualized_return` = `risk_analysis(report["return"])` 的年化收益（策略绝对收益）；
- `mean` / `std` / `information_ratio` / `max_drawdown` = `risk_analysis(report["return"] − report["bench"])`
  即**超额收益**（相对 SH000300）的口径；
- `daily_turnover_mean` = 逐日 `report["turnover"]` 的均值（组合换手）。

**分层表现**（`layered.csv`，来自 `common/eval/layered.py::layered_returns`, n_groups=10）：每个交易日
内按 pred 排名分 10 组等权，组收益 = 组内次日 label 均值；`g0` 为预测最低组、`g9` 为最高组，
`long_short = g9 − g0`（多空组合收益）。表中「组间单调性」= 逐日对 10 组收益与组序号求
Spearman 后在日度上的均值（1 = 完美单调）。

### 3.3 读法与限定

- **排序性（RankIC 层）保住了，组合层（回测/多空）没完全保住**。同一批预测，按 RankIC 只掉
  2.8%，但分层 long_short 年化从 0.294 掉到 0.156（约为对照的 53%）、long_short Sharpe 从
  1.50 掉到 0.73。原因是 RankIC 是全局平均排序相关，而 long_short 只吃两端组的信息；公式化把第一层
  压成每特征一条边，损失的主要是**极端分位**的区分度，中段排序基本不变。这也解释了为什么 IC 层面
  表现「几乎无损」、组合层面却打了对折。
- **回测层两个模型方向相反，不构成「蒸馏更优」的证据**：蒸馏的超额 IR 高（0.918 vs 0.363）、MaxDD
  更浅，但多空组合与分层单调性都更差——前者是 topk-30 组合 + 成本 + 基准择时下的结果，后者是纯
  多的组合口径，两者是不同问题。**在只看这一份 test 窗口、且未做种子重复的前提下，这些差异都不应
  单独作为结论**（B7 种子 std≈0.0027 的量级与这里的分层差异同阶）。
- 组间单调性两个模型都偏低（0.045 / 0.068），说明 Alpha158 在 2023+ 的截面预测两端噪声大，
  这与 B1/README 记的「单因子 Alpha158 在 2023+ regime 弱化」一致。
- **结论收敛**：强主张只保留「按 RankIC 衡量，158 条公式几乎无损（97.2%）」；组合层表现有可观
  回撤，「可读公式替代样条」在组合视角**有代价**，需在 README 措辞中保留这个限定。

## 4. 公式表（158 条，冻结第一层）

产物 `symbolic-distill/formulas.csv` / `formulas.md`（按 edge_norm 降序，含特征名、汇入的隐藏
节点、函数族、R²、`a/b/c/d` 与人类可读公式串）。函数族分布：sin 116、sigmoid 23、tanh 18、
sgn·log(1+|x|) 1；全部 158 条 `snap_status=snapped`，拟合 R² 最小 0.9931、均值 0.9975。样例：

| 特征 | 隐藏节点 | 公式 | R² |
|---|---|---|---|
| RESI5 | h5 | `0.600*sigmoid(1.557*x-2.643)-0.056` | 0.9974 |
| RESI30 | h18 | `0.415*sigmoid(1.757*x-3.157)-0.026` | 0.9975 |
| RESI60 | h19 | `-0.105*sign(1.961*x-4.390)*log1p(|1.961*x-4.390|)-0.195` | 0.9933 |
| CORD30 | h19 | `-0.835*sigmoid(1.039*x-1.710)+0.109` | 0.9996 |

口径说明：公式拟合的是 B4 定义下的**完整边函数** φ = spline + base·SiLU，定义域为
RobustZScoreNorm（clip ±3）后的标准化输入 x∈[−3,3]；`a/b/c/d` 就是 B4 `symbolic_snap_edges.csv`
里对应行的数值，B15 只做 JOIN 消费、未改动原文件（已逐列核对一致）。

## 5. 限定与风险

- **保留率是单 seed 结果**。对照与蒸馏都用 seed 42；B7 已量化 KAN 的 test RankIC 种子 std ≈ 0.0027，
  ≥ 本次差值 0.0007，即 97.2% 这个点估计的置信区间会跨过 100%。结论「公式化几乎无损」成立，
  但不宣称「蒸馏优于原模型」。
- **第一层被替换的是「每特征一条最强边」**。原 KAN 第一层每特征有 24 条边，B15 只保留最强的
  一条（其余边不存在），因此本实验同时验证了两件事：最强边承载了主要信号、且多边冗余度很高。
- 上方 valid 差距（−0.0073）提示：若换成用 valid 指标讲故事，损失看起来会大得多；test 上的
  97.2% 才是对「部署性能保留」的正确读数——但注意这只是在 **RankIC** 口径下成立，组合层代价
  见第 3 节。
- 第一层「0 可训练参数」由 `n_params=240`（仅第二层）证实。
