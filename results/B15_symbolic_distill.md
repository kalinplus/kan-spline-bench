# B15：KAN 符号蒸馏 — 158 条可读公式 + 重训第二层，RankIC 保留 97.2%（IC 68.3%）

分析对象：B1 主 KAN（`[158,24,1]`，grid 5 / order 3 / ±3）。把 B4 已 snap 的 **158 个特征最强边
符号公式**（每个特征恰好一条边，冻结不再训练）作为第一层，替换掉的不仅是可读性诉求——原来整层
样条参数（158×24 条边）都被替换成 158 条闭式函数。只重训第二层（24→1 的同一
KANLayer），报告相对原 KAN 的 RankIC 保留比例。脚本：`scripts/run_b15_symbolic_distill.py`
（本仓库 feature/b15-symbolic-distill 分支），产物：`common/runs/kan/symbolic-distill/`。

**一句话结论**：把第一层压成 158 条人能读懂的公式（`0.600·sigmoid(1.557x−2.643)−0.056`
这种形式）后，测试集 **RankIC 只掉 2.8%**（0.02643 → 0.02570，保留 **97.2%**），但 **IC（Pearson）
只保留 68.3%**（0.01977 → 0.01351）。两者不矛盾：公式化把预测压得更温和（预测 IQR 几乎减半），
秩序几乎不变而幅度信息损失明显（见第 4 节）。因此完整表述是「**排序几乎无损、幅度与组合层有代价**」。

## 0. 方法与口径

- **第一层（冻结，非训练）**：对 158 个特征各取 B4 判定的最强边（边范数 L1 口径），其函数为
  `φ(x) = a·f(b·x+c) + d`，`f ∈ {x, x², x³, |x|, sgn·log(1+|x|), sin, sigmoid, tanh}`
  （与 B4 `symbolic_snap_edges.csv` 同一候选族与拟合口径），参数直接读自 B4 产物，不重新拟合。
  158 条公式按 `strongest_hidden` 汇入 24 个隐藏节点（每节点 1–17 条入边，24 个节点全部被用到）。
  第一层以 buffer 形式注册——**0 个可训练参数**。
- **第二层（重训）**：与原 [158,24,1] KAN 的第二层完全同构（KANLayer 24→1，grid 5/order 3）。
  重训后的可训练参数 = 24 条边 × 10 = **240**（对照整模型为 38,160）。
- **paired 对照**：同一脚本、同一 seed(42)、同一 `run_b1.train_torch` 路径训练一次**原样条 KAN**
  （第一层可训）。两个模型唯一的差异 = 第一层是冻结的符号公式还是可训样条。
- **选择与评分纪律**：early stop / 模型选择只看 valid；test 集每个模型**只评分一次**，未基于
  test 做任何选择。
- **训练配置**：照抄 `run_b1.py`（AdamW lr 1e-3 / wd 1e-4 / batch 4096 / max 200 epoch /
  patience 15，CUDA，seed 42）；未调任何新超参。
- **回测/分层层汇总**：`python scripts/run_b15_symbolic_distill.py --summary-only` 只读已落盘的
  `backtest_report.csv` / `layered.csv` / `pred.parquet` 生成 `backtest_layer_compare.json`，
  不进入训练路径（本报告第 3–4 节即由此产出）。

## 1. 核心结果：RankIC 保留 97.2%（IC 保留 68.3%）

| **RankIC 保留率（vs paired 对照）** | **97.24%** |
| test IC（Pearson，蒸馏 / 对照） | 0.013515 / 0.019774 |
| **IC 保留率（vs paired 对照）** | **68.35%** |
| test RankIC（B1 主表 KAN，外部参考） | 0.026425 |
| RankIC 保留率（vs B1 参考） | 97.24% |

关于两个分母的关系：**主分母是本次同脚本跑出的 paired 对照**（同 seed、同代码路径、唯一差异
是第一层），它是干净的因果对照。它同时几乎完美复现了 B1 主表的 KAN（test RankIC
0.026425210 vs B1 0.026425067，差 1.4e-7；valid 0.02775 @ epoch 5 与 B1 日志逐点一致），
所以两个分母给出同一个 97.2%。B1 参考只作外部交叉印证，不作为主口径。

**RankIC 与 IC 保留率为何差这么多**：RankIC（Spearman）对单调重标度不变，只要排序不变就
守恒，因此公式化后保留 97.2%；IC（Pearson）对预测的幅度与极值敏感，而符号公式把预测压得
更温和（见第 4 节），于是只保留 68.3%。这也预告了第 3 节：靠两端极值的 long_short 组合会
明显走弱。

## 3. 回测层对比（验收 #6）

分析产物：`backtest_layer_compare.json`（由脚本 `--summary-only` 汇总段只读生成，**未重跑训练**）。

### 3.1 口径核实（重要：`backtest` 字段实际含义）

回测协议（`run_b1.evaluate_dump`，两模型同一份代码）：逐日截面信号 → `TopkDropoutStrategy(topk=30,
 n_drop=1)`，`deal_price=close`、`limit_threshold=0.095`、`trade_unit=100`、`min_cost=5`，成本
`open 0.05% / close 0.15%`（**已扣成本**：逐日 `cost` 列均值 6.3e-5 / 6.8e-5，回测报告里的
`return` 是净收益），基准 SH000300，区间 test 2023-01-03 ~ 2026-07-23（860 个交易日）。

指标定义来自 `qlib.contrib.evaluate.risk_analysis`（`evaluate.py:27`，默认 `freq="day"` → **N=238**、
`mode="sum"`）与 `scripts/run_b1.py:210-212`。注意 `metrics.json` 的 `backtest` 字段容易误读：

| 字段 | 实际口径 | 来源 |
|---|---|---|
| `annualized_return` | **不是年化值**。`run_b1.py:211` 写的是 `risk_analysis(report["return"]).iloc[0,0]`，即 risk_analysis 输出的**第一行 `mean`** = **日均绝对收益**（未年化） | run_b1.py:211 |
| `mean` / `std` | 策略**超额**收益（`return − bench`）的日均值与日度标准差（ddof=1） | run_b1.py:210 |
| `information_ratio` | 超额 `mean/std × √238`（注意是 **238** 而非 252） | qlib N=238 |
| `max_drawdown` | 超额序列的 **加法累加回撤** `(cumsum − cumsum.cummax()).min()`，非百分比回撤 | qlib mode="sum" |
| `daily_turnover_mean` | 逐日 `report["turnover"]` 均值 | run_b1.py:212 |

所以 named「年化」的 0.000659 / 0.000430 实际是**日均绝对收益**（若按 qlib 口径 ×238 年化则为
0.157 / 0.102；按 ×252 为 0.166 / 0.108），而 0.00037 是另一个量：**日均超额收益**。报告中一律按
上述实际口径引用，不照抄字段名。

**分层表现**（`layered.csv`，来自 `common/eval/layered.py::layered_returns`, n_groups=10）：每个
交易日内按 pred 排名分 10 组等权，组收益 = 组内次日 label 均值；`g0` 预测最低组、`g9` 最高组，
`long_short = g9 − g0`。「组间单调性」= 组序号 (0..9) 与 10 组平均收益的 Spearman（每个模型一个值，
1 = 完美单调）；「long_short IR」= 日收益均值/std × √238。

### 3.3 读法与限定

- **排序层保住了，组合层没完全保住**：long_short 日收益 0.001168 → 0.000618（约为对照的 53%）、
  long_short IR 1.456 → 0.712、组间单调性 0.952 → 0.782。long_short 只吃两端两组的信息，而
  公式化把预测压得更温和（见第 4 节），极端分位被削弱，中段排序基本不变——这正解释了为何
  RankIC 几乎无损、多空组合却打对折。
- **回测组合层与分层多空方向相反，不构成「蒸馏更优」的证据**：蒸馏的日均绝对/超额收益与超额 IR
  更高、加法累加回撤更浅、换手与成本更低（0.0631 vs 0.0688，成本 6.3e-5 vs 6.8e-5），但 long_short
  与组间单调性更差。前者是 topk-30 多头组合 + 成本 + 基准择时的口径，后者是 decile 多空口径，
  是不同问题。**所有差异均为单一 test 区间（2023-01~2026-07）、单 seed（42）下的观测值，不得
  表述为普适结论**（B7 测得 test RankIC 种子 std≈0.0027，与这里的分层/回测差异同阶）。
- 回测 IR 更高的直接原因是分子（日均超额收益）高、**而非波动低**——蒸馏的超额日波动实际略高
  （0.006149 vs 0.005839）。日均收益是全部指标里噪声最大的量，故这一条尤其不可当作结论。
- 组间单调性两模型都偏低（0.78 / 0.95 是 10 个组均值的排序相关，受两端组噪声影响），与
  README 记的「Alpha158 在 2023+ regime 弱化」一致。
- **结论收敛**：强主张只保留「按 RankIC 衡量，158 条公式几乎无损（97.2%）」；IC 与组合层均有
  可观损失，措辞需限定为「**该区间该口径下的观测**」。

## 4. IC 与 RankIC 保留率背离的解释

同一批预测，RankIC 保留 97.2% 而 IC 只保留 68.3%，回测层 IR/回撤/换手却在蒸馏侧更好。基于**已有
数字**（不新增训练实验）的解释：

1. **两个指标的敏感度不同**：RankIC（Spearman）是秩相关，对预测做任何单调变换都守恒——公式化
   保留了两两相对秩序，故 RankIC 几乎不动。IC（Pearson）是线性相关，直接受预测幅度与极值影响。
2. **符号公式把预测压温和了**（有直接证据）：蒸馏预测 std 0.0472 vs 对照 0.0781（**−40%**）、
   IQR 0.0597 vs 0.0878（−32%）、日度截面极差均值 0.263 vs 0.492（**约减半**）。每特征只剩一条
   边，第一层输出幅度自然比 24 条边求和更小，第二层只能在其基础上重标度。幅度是 IC 的分子，
   因此 IC 掉得多。
3. **与分层结果自洽**：long_short 只取两端 decile，压温和的预测使 g9/g0 的区分度下降，于是
   long_short 项（年化 0.294 → 0.156）与组间单调性（0.952 → 0.782）同步走弱——与“IC 损失来自
   极值、而非中段秩序”一致。
4. **换手/成本侧反向有独立机制**：预测更温和 → 排序更稳定 → 换手更低（0.0631 vs 0.0688），
   成本更低（6.3e-5 vs 6.8e-5），这对净 IR 有利；而 topk-30 多头组合只依赖头部排序的稳定性，
   不要求幅度校准，所以回测层反而更好。两条方向不矛盾：**一个吃幅度（IC/多空），一个吃
   排序稳定（RankIC/topk 回测）**。

需要克制的地方：第 4 点的证据（IR 0.918 vs 0.363）叠在 单窗口单 seed 上，且分子（日均超额
收益）是本报告噪声最大的量；它只能算与机制一致的观察，不能当成结论，更不能反过来当作
「蒸馏更好」的证据。

## 6. 限定与风险

- **保留率是单 seed、单 test 区间结果**。对照与蒸馏都用 seed 42，test 区间单一（2023-01-03 ~
  2026-07-23）；B7 已量化 KAN 的 test RankIC 种子 std ≈ 0.0027，≥ 本次差值 0.0007，即 97.2% 这个
  点估计的置信区间会跨过 100%。「公式化几乎无损」成立，但不得写成「蒸馏优于原模型」。
- **结论口径分层**：RankIC 保留 97.2%、IC 保留 68.3%、long_short 日收益保留约 53%。引用时必须
  写明是哪个口径；「无损」只在 RankIC 口径下成立。
- **`metrics.json` 的 `backtest.annualized_return` 是误导字段**：它实际是**日均绝对收益**（见 3.1）。
  后续任何引用 B1/B15 回测数字的分析都应先看本报告 3.1 或改用
  `backtest_layer_compare.json` 里的显式字段。
- **第一层被替换的是「每特征一条最强边」**。原 KAN 第一层每特征有 24 条边，B15 只保留最强的
  一条（其余边不存在），因此本实验同时验证了两件事：最强边承载了主要信号、且多边冗余度很高。
- valid 差距（−0.0073）远大于 test 差距（−0.0007）：若用 valid 指标讲故事，损失看起来会大得多；
  test 上的 97.2% 才是「部署性能保留」的读数——但同样只在 RankIC 口径下成立。
- 第一层「0 可训练参数」由 `n_params=240`（仅第二层）证实。
