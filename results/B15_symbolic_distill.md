# B15：KAN 符号蒸馏 — 158 条可读公式 + 重训第二层，RankIC 保留 97.2%（IC 68.3%）

分析对象：B1 主 KAN（`[158,24,1]`，grid 5 / order 3 / ±3）。把 B4 已 snap 的 **158 个特征最强边
符号公式**（每个特征恰好一条边，冻结不再训练）作为第一层，替换掉的不仅是可读性诉求——原来整层
样条参数（158×24 条边）都被替换成 158 条闭式函数。只重训第二层（24→1 的同一
KANLayer），报告相对原 KAN 的 RankIC 保留比例。脚本：`scripts/run_b15_symbolic_distill.py`
（本仓库 feature/b15-symbolic-distill 分支），产物：`common/runs/kan/symbolic-distill/`。

**一句话结论**：把第一层压成 158 条人能读懂的公式（`0.600·sigmoid(1.557x−2.643)−0.056`
这种形式）后，测试集 **RankIC 只掉 2.8%**（0.02643 → 0.02570，保留 **97.2%**），但 **IC（Pearson）
只保留 68.3%**（0.01977 → 0.01351）。两者不矛盾：公式化把预测压得更温和（预测 IQR 几乎减半），
秩序几乎不变而幅度信息损失明显（见第 4 节）。但在**横截面区分度**上对照明显更强——组间单调性
0.952 vs 0.782、long_short 日收益 0.001168 vs 0.000618（IR 0.094 vs 0.046），而**全组合回测**指标
（日均收益、加法回撤、换手/成本）在本地区间内蒸馏侧更好。分层的完整表述见 3.3 / 3.4，
**不得笼统写成「蒸馏优于原模型」**。

## 0. 方法与口径

- **第一层（冻结，非训练）**：对 158 个特征各取 B4 判定的最强边（边范数 L1 口径），其函数为
  `φ(x) = a·f(b·x+c) + d`，`f ∈ {x, x², x³, |x|, sgn·log(1+|x|), sin, sigmoid, tanh}`
  （与 B4 `symbolic_snap_edges.csv` 同一候选族与拟合口径），参数直接读自 B4 产物，不重新拟合。
  158 条公式按 `strongest_hidden` 汇入 24 个隐藏节点（每节点 1–17 条入边，24 个节点全部被用到）。
  第一层以 buffer 形式注册——**0 个可训练参数**。
- **第二层（重训）**：与原 [158,24,1] KAN 的第二层完全同构（KANLayer 24→1，grid 5/order 3）。
  重训后的可训练参数 = 24 条边 × 10 = **240**（对照整模型为 38,160）。
- **paired 对照**：同一脚本、同一 seed(42)、同一 `run_b1.train_torch` 路径训练一次**原样条 KAN**
  （第一层可训）。两个模型唯一的差异 = 第一层是冻结的符号公式还是可训样条。
- **选择与评分纪律**：early stop / 模型选择只看 valid；test 集每个模型**只评分一次**，未基于
  test 做任何选择。
- **训练配置**：照抄 `run_b1.py`（AdamW lr 1e-3 / wd 1e-4 / batch 4096 / max 200 epoch /
  patience 15，CUDA，seed 42）；未调任何新超参。
- **回测/分层层汇总**：`python scripts/run_b15_symbolic_distill.py --summary-only` 只读已落盘的
  `backtest_report.csv` / `layered.csv` / `pred.parquet` 生成 `backtest_layer_compare.json`，
  不进入训练路径（本报告第 3–4 节即由此产出）。

明显走弱。

`mode="sum"`）与 `scripts/run_b1.py:210-212`。**同一个错命名在整个项目里重复**：
`common/scripts/run_baselines_builtin.py:86`、`run_alpha158_lgb.py:118`、`run_master*.py`、

| 字段 | 实际口径 | 来源 |

| `annualized_return` | **不是年化值**。写的是 `risk_analysis(report["return"]).iloc[0,0]`，即 risk_analysis 输出的**第一行 `mean`** = **日均绝对收益**（未年化） | run_b1.py:211（同 run_baselines_builtin.py:86 等） |

**`information_ratio` 口径的数值验证（已排除两种误读）**：

| 变体 | 蒸馏 | 对照 | 是否等于 metrics 值 |
|---|---|---|---|
| **超额 mean/std × √238**（metrics 实际口径） | **0.918102** | **0.362998** | ✅ 与 `metrics.json` 逐位吻合（<1e-9） |

防住的误报点。

**回测区间两侧完全一致**（排除 IR 差异来自区间差异的质疑）：两份 `backtest_report.csv` 均为
860 个交易日、日期序列逐行相等（`datetime` 列 `equals=True`），均为 2023-01-03 ~ 2026-07-23，

所以 named「年化」的 0.000659 / 0.000430 实际是**日均绝对收益**，而 0.00037 是另一个量：
**日均超额收益**。报告中一律按上述实际口径引用，不照抄字段名。

**分层表现**（`layered.csv`，来自 `common/eval/layered.py::layered_returns`, n_groups=10）：每个
交易日内按 pred 排名分 10 组等权，组收益 = 组内次日 label 均值；`g0` 预测最低组、`g9` 最高组，
`long_short = g9 − g0`。「组间单调性」= 组序号 (0..9) 与 10 组平均收益的 Spearman（每个模型一个值，
1 = 完美单调）；「long_short IR」同时给**日均口径**（mean/std）与年化口径（×√238）。

### 3.3 内部张力：RankIC 保住 97.2%，为何横截面区分度下降？

这是本报告最需要解释清楚的一点，两个层面必须**如实并列**，不能取其一：

| 层面 | 口径 | 蒸馏 | 对照 | 谁占优 |
|---|---|---|---|---|
| 全局秩相关 | test RankIC | 0.025696 | 0.026425 | 几乎持平（97.2%） |
| 横截面区分度 | 组间单调性 Spearman(组序, 组均收益) | 0.782 | 0.952 | **对照明显更强** |
| 横截面区分度 | long_short 日收益 | 0.000618 | 0.001168 | **对照明显更强** |
| 横截面区分度 | long_short IR（日均 mean/std） | 0.046 | 0.094 | **对照约 2×** |
| 极端组 | g0（预测最低组） | +0.000006 | −0.000353 | 对照更会“嫌弃差股” |
| 极端组 | g9（预测最高组） | 0.000624 | 0.000815 | 对照更会“选出好股” |
| 全组合 | 日均绝对收益 / 超额收益 | 0.000659 / 0.000366 | 0.000430 / 0.000137 | 蒸馏占优 |
| 全组合 | 加法累加回撤 | −0.1137 | −0.1467 | 蒸馏更浅 |
| 全组合 | 日均换手 / 成本 | 0.0631 / 6.3e-5 | 0.0688 / 6.8e-5 | 蒸馏更低 |

**为何两者能同时成立**（基于已有数字，无新实验）：

1. **RankIC 是全局秩相关，对“整体秩序”敏感、对“局部幅度”不敏感**。公式化保留了大部分相对
   秩序，所以 RankIC 只掉 2.8%；但分层单调性与 long_short 只依赖**两端组**的区分度，是局部量。
   关键证据在极端组：蒸馏的 g0 = +6e-6（几乎与全局均值持平，不能把差股排出去），
   而对照的 g0 = −3.5e-4（显著为负）；g9 也是对照高（8.2e-4 vs 6.2e-4）。即**尾部排序质量
   下降**，而中段排序基本未变——这正好是全局 Spearman 看不出来、但分层指标直接感知到的。
2. **刚性公式压缩了预测的动态范围**（直接证据）：蒸馏预测 std 0.0472 vs 0.0781（**−40%**）、
   IQR 0.0597 vs 0.0878（−32%）、日度截面极差均值 0.263 vs 0.492（**约减半**）。每特征只保留
   一条边，第一层输出幅度自然比 24 条边求和更小；第二层只能在其基础上重标度，无法恢复已丢失
   的幅度信息。幅度被压缩后，两端样本的“拉开程度”变小，decile 多空组合的收益自然减半。
3. **全组合回测占优有独立机制，与上面不矛盾**：预测更温和 → 排序更稳定 → 换手更低
   （0.0631 vs 0.0688）、成本更低（6.3e-5 vs 6.8e-5）；而 topk-30 多头组合只依赖头部排序的
   稳定性，不要求幅度校准。两条方向不矛盾：**一个吃幅度（IC / decile 多空），一个吃排序稳定
   （RankIC / topk 回测）**。

### 3.4 结论口径与限定（不得笼统表述）

- 允许的表述：**「IC（RankIC）层几乎无损（97.2%）、横截面区分度有损失（单调性 0.952→0.782、
  long_short IR 0.094→0.046）、全组合回测指标在该区间内蒸馏占优」**。
- 禁止的表述：「蒸馏优于原模型」、「公式化无损」、「可读公式完全替代样条」。三者都跨了层面。
- **所有差异均为单一 test 区间（2023-01~2026-07）、单 seed（42）下的观测值**（B7 测得 test
  RankIC 种子 std≈0.0027，与这里的分层/回测差异同阶）；且全组合侧的 IR 优势来自分子
  （日均超额收益，全部指标里噪声最大的一项），**不是**来自波动更低（蒸馏超额日波动反而略高：
  0.006149 vs 0.005839）。
- 组间单调性两模型都不是完美单调，与 README 记的「Alpha158 在 2023+ regime 弱化」一致。

## 4. IC 与 RankIC 保留率背离的解释

同一批预测，RankIC 保留 97.2% 而 IC 只保留 68.3%，回测层 IR/回撤/换手却在蒸馏侧更好。基于**已有
数字**（不新增训练实验）的解释：

1. **两个指标的敏感度不同**：RankIC（Spearman）是秩相关，对预测做任何单调变换都守恒——公式化
   保留了两两相对秩序，故 RankIC 几乎不动。IC（Pearson）是线性相关，直接受预测幅度与极值影响。
2. **符号公式把预测压温和了**（有直接证据）：蒸馏预测 std 0.0472 vs 对照 0.0781（**−40%**）、
   IQR 0.0597 vs 0.0878（−32%）、日度截面极差均值 0.263 vs 0.492（**约减半**）。每特征只剩一条
   边，第一层输出幅度自然比 24 条边求和更小，第二层只能在其基础上重标度。幅度是 IC 的分子，
   因此 IC 掉得多。
3. **与分层结果自洽**：long_short 只取两端 decile，压温和的预测使 g9/g0 的区分度下降，于是
   long_short 项（年化 0.294 → 0.156）与组间单调性（0.952 → 0.782）同步走弱——与“IC 损失来自
   极值、而非中段秩序”一致。
4. **换手/成本侧反向有独立机制**：预测更温和 → 排序更稳定 → 换手更低（0.0631 vs 0.0688），
   成本更低（6.3e-5 vs 6.8e-5），这对净 IR 有利；而 topk-30 多头组合只依赖头部排序的稳定性，
   不要求幅度校准，所以回测层反而更好。两条方向不矛盾：**一个吃幅度（IC/多空），一个吃
   排序稳定（RankIC/topk 回测）**。

需要克制的地方：第 4 点的证据（IR 0.918 vs 0.363）叠在 单窗口单 seed 上，且分子（日均超额
收益）是本报告噪声最大的量；它只能算与机制一致的观察，不能当成结论，更不能反过来当作
「蒸馏更好」的证据。

| RESI60 | h19 | `-0.105*sign(1.961*x-4.390)*log1p(|1.961*x-4.390|)-0.195` | 0.9933 |
| CORD30 | h19 | `-0.835*sigmoid(1.039*x-1.710)+0.109` | 0.9996 |

口径说明：公式拟合的是 B4 定义下的**完整边函数** φ = spline + base·SiLU，定义域为
RobustZScoreNorm（clip ±3）后的标准化输入 x∈[−3,3]；`a/b/c/d` 就是 B4 `symbolic_snap_edges.csv`
里对应行的数值，B15 只做 JOIN 消费、未改动原文件（已逐列核对一致）。

## 6. 限定与风险

- **保留率是单 seed、单 test 区间结果**。对照与蒸馏都用 seed 42，test 区间单一（2023-01-03 ~
  2026-07-23）；B7 已量化 KAN 的 test RankIC 种子 std ≈ 0.0027，≥ 本次差值 0.0007，即 97.2% 这个
  点估计的置信区间会跨过 100%。「公式化几乎无损」成立，但不得写成「蒸馏优于原模型」。
- **结论口径分层**：RankIC 保留 97.2%、IC 保留 68.3%、long_short 日收益保留约 53%；**横截面
  区分度（分层单调性/多空）对照更强，而全组合回测指标在本区间蒸馏占优**。引用时必须写明是
  哪个口径；「无损」只在 RankIC 口径下成立，不得写成「蒸馏优于原模型」。
- **`metrics.json` 的 `backtest.annualized_return` 是误导字段**：它实际是**日均绝对收益**（见 3.1），
  且同一错命名广泛存在于 `common/scripts/run_baselines_builtin.py:86` 等与 B1/B8/B10/B6 回测脚本中。
  后续任何引用回测数字的分析都应先看本报告 3.1 或改用 `backtest_layer_compare.json` 里的显式字段。
- **`information_ratio` 是超额口径且用 √238**（已数值逐位验证，见 3.1），不是绝对收益 × √252/√242；
  误用会让 control 侧 IR 从 0.363 虚报到 0.558。
- **第一层被替换的是「每特征一条最强边」**。原 KAN 第一层每特征有 24 条边，B15 只保留最强的
  一条（其余边不存在），因此本实验同时验证了两件事：最强边承载了主要信号、且多边冗余度很高。
- valid 差距（−0.0073）远大于 test 差距（−0.0007）：若用 valid 指标讲故事，损失看起来会大得多；
  test 上的 97.2% 才是「部署性能保留」的读数——但同样只在 RankIC 口径下成立。
- 第一层「0 可训练参数」由 `n_params=240`（仅第二层）证实。
