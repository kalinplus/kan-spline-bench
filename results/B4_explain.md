## 1. 样条形状：KAN 把因子扭成了什么

图集 `explain/spline_curves_top12_labeled.png`（边范数 top-12，验收要求 ≥10）。最强边判读
（自动分类 + 人工复核，修正记录见完整报告）：

- **单调门控（延迟激活 S 型）**：RESI5/RESI30/ROC30 —— B1 主模型把它们读作标准化值
  x>0~1 后才显著激活的 S 型门控，snap 成 sigmoid/tanh（R² ≥ 0.997）。跨 seed 复核（§4）：
  RESI5 的最强边响应曲线在 5 个 seed 间 |corr| ≥ 0.987 稳定复现，但其中 6/10 对为镜像翻转、
  部分 seed 的同因子边更接近近线性上升——所以「模型自己发现了乖离率/动量的阈值门控」是
  **主模型的具体读法**，跨 seed 稳定的是该因子的单变量响应曲线本身。
- **单调递减（端部饱和）**：RESI60、CORD30、STD60、WVMA30、BETA60 —— 左端饱和平台后
  近线性下坠；RESI60 为对数压缩型（snap sgn·log，R² 0.993）。
- **峰谷形（U / 倒 U）**：RESI20、MA5、KLOW、MIN60 —— 谷/峰底系统性偏左（≈ −1.5σ），
  snap 成单瓣 sin（R² ≥ 0.998），本质是端部平缓的饱和峰谷。其中 **KLOW 的 top-12 地位为
  主模型特有**（B14 中 0/5 seed 入榜，见 §4）；RESI20/MA5/MIN60 的峰谷曲线跨 seed |corr| ≥ 0.98。
- 全量 158 特征最强边分布：峰谷形及饱和变体 145 条（92%）vs 纯单调 13 条。

### 1.1 密度约束下的判读（B13 增补）

图集 v2 在每张子图叠加该特征训练集输入分布直方图（半透明背景）与低密度区标识：口径为
训练集 60 bin 直方图（[-3,3]），低密度区 = 训练质量落在 0.5–99.5 分位带之外的两端尾部
（灰色阴影，最强边在阴影内降透明）——样条在该区域的形状是外推，不作解读。逐因子
「形状变化质量」在高密度带内的占比（shape-mass ratio = ∫|φ−median(φ)| 在带内份额；
≥0.90 high / 0.60–0.90 mostly_high / <0.60 low）落盘 `explain/density_overlay.json`，
重跑日志 `explain/b13_rerun.log`：

- **high（8 个）**：RESI5、RESI30、RESI60、RESI20、MA5、ROC30、WVMA30（0.910）、BETA60
  —— 形状主体有数据支撑。注意其中重尾因子分位带退化为全域（0.5/99.5 分位被 ±3 clip
  压界），此时 ratio 恒为 1，密度约束由直方图承担：RESI5 门控阈值段 x≈0~1 位于密度
  主峰，「x>0~1 才显著激活」的方向性判读**确认**，但 x>1.5 平台段密度趋零，平台高度只宜
  作方向性解读（其余 band 全域因子同理）。
- **mostly_high（2 个）**：STD60、KLOW（ratio 0.846）—— 单侧尾部外推，主体判读维持。
- **low（2 个，判读降级）**：**CORD30**（0.457，带 [-3,+1.67]）—— 左端饱和平台位于高密度
  核心可信，但主下降段落在 x>+1.67 外推区，下坠斜率与深度不解读；**MIN60**（0.275，
  带 [-3,+1.13]）—— 谷底偏左（≈−1.5σ）的定位在带内可信，右上升臂幅度主要在外推区，
  不解读。

结论：top-12 判读 10 个维持或限定维持，2 个（CORD30、MIN60）降级——第 1 节的形状故事
方向不变，但涉及低密度区的形状细节以本节为准。

### 1.2 Case study：两条可对外讲述的经济学读法（面试口径）

从 §1 的判读中选证据链最完整的两条，作为「KAN 学到的非线性有经济学含义」的代表案例。
**读法范围（先于一切表述）**：这里读的是「模型为该因子学到的单变量响应曲线」（最强边
通道形态），它承载排序信息（B15：冻结后 RankIC 保留 97.2%），但**不等价于该因子对预测
的逐行边际效应**——最强边单独只解释该因子输出敏感度方差的 1.4%~16.6%（RESI5 为 1.6%，
CORD30/MIN60 相关为负；见 `docs/interpretability-results.md` §5.4）。因此以下全部读法
的主语是「学到的响应曲线」，不是「因子的作用」或「模型对该因子的使用方式」。**方向与
命名是 B1 主模型的具体读法，跨 seed 稳定的是曲线本身（至多镜像）**；阈值/饱和两类结构
对镜像自由度不敏感（镜像只翻转方向，不破坏「存在阈值」「存在饱和」这两个结构事实），
这也是选它们做案例的原因之一。

**Case 1 — RESI5（5 日乖离率）：S 型阈值门控，「趋势确认」结构。**
主模型把 RESI5 最强边学成 sigmoid/tanh 门控（R²≥0.997）：标准化乖离率在 x≈0~1 过渡带
以下近乎零激活，越过阈值后才线性跟随进入高激活段；该阈值段位于训练密度主峰内（§1.1
B13 确认方向性判读，x>1.5 平台段密度趋零只作方向性解读），响应曲线跨 5 seed
|corr|≥0.987 稳定复现，且 RESI5 是 5/5 seed 全勤因子、KAN/LGB 重要性 top-20 的 7 个交集
因子之一（§3）。经济学读法（对曲线形状的解读，非因子作用声明）：这条响应曲线与人工
动量策略「趋势确认后再跟随」的阈值结构同构。
（对外一句话：「模型为 5 日乖离率学到的响应曲线是一道阈值门控——小偏离近乎零响应，
越过确认阈值后才线性给分，与趋势确认的交易实践同构。」）

**Case 2 — STD60（60 日波动率）：端部饱和的单调递减，低波动溢价。**
主模型读法：低波动区间响应平坦（平台），进入高波动区间后在密度覆盖范围内近线性下坠
（B13 判 mostly_high、主体维持，更极端尾部属外推不解读）。注意 STD60 不在 §4 的 ≥3/5
seed 入榜名单（2/5），top-12 地位属主模型特有，案例强度低于 Case 1。经济学读法（对
曲线形状的解读）：经典低波动溢价异象（low-volatility anomaly）的形态版本——响应曲线
对低波动区间内部差异不敏感、区分度集中在高波动端：曲线形状与「风险惩罚分段化」的
直觉同构，而非全局线性排序。
（对外一句话：「60 日波动率的响应曲线不是线性减分：低波动区间几乎不区分，高波动区间
才线性扣分——曲线形态与低波动溢价的门控直觉同构。」）

家族级补充（一句话，不做单因子展开）：全量 158 条最强边中 92% 为峰谷/饱和形态、纯
线性 0 条（§2）；符号蒸馏将第一层冻结为这批可读公式后 test RankIC 保留 97.2%（§5）
——曲线形态与排序能力不冲突；幅度信息（IC 保留 68.3%）与逐行边际效应不在本节声明
范围内（§5.4 与 `docs/interpretability-results.md` §5.4）。

分析产物不受本节改动影响：重跑后 `shape_classification.csv` / `importance_compare.csv` 与
B4 原版逐字节一致；`symbolic_snap_edges.csv` 有 5 行 `x^3` 候选出现 1e-11 级参数简并抖动
（可辨识量 `a·b³`、`c/b` 两版一致、max|Δr²|=1.5e-11，`best_cand` / `snap_status` 零差异），
已恢复原版以保证产物不变。

## 2. 符号化：snap 结果与不可 snap 边

手动函数族拟合（8 候选 × affine wrap a·f(b·x+c)+d；未用 pykan——与 efficient-kan 权重布局
不兼容且有 torch 升级风险，如实报告）：

- 全量 3,792 边：**3,681 snapped（97.2%）、44 borderline、60 not snappeable、7 negligible 死边**；
  60 条不可 snap 边全部为弱边（max|φ| 中位 0.016 vs snapped 边 0.116），逐条标注不硬凑。
- **158 个特征的最强边全部 snap 成功，R² ≥ 0.99**。
- 解读口径：sigmoid ≡ tanh（affine 等价族）；snap 成 sin 的边 99.3% 在定义域内不足一个周期，
  sin 在此是"端部平缓峰谷"的基函数而非周期信号；纯线性 x 零条——没有一条边是线性的。

## 3. 重要性交叉印证：KAN 边范数 vs LightGBM gain

| 口径 | 结果 |
|------|------|
| 全量 158 特征 rank Spearman | **0.527** |
| top-20 交集（7） | RESI5、CORD30、STD60、MIN60、ROC30、KMID、VWAP0 |
| 仅 KAN top-20（13） | RESI{10,20,30,60}、MA5、KLOW、WVMA30、BETA60、QTLD10、OPEN0、MIN10、KLEN、BETA10 |
| 仅 LGB top-20（13） | STD30、KSFT、MIN30、IMXD5、MAX60、CORD60、QTLU5、IMIN5、CORD5、RANK10、LOW0、MA10、RANK5 |

分歧讨论：

1. **RESI 家族**：KAN 五个窗口乖离率全部进 top-20（份额合计 6.6%），LGB 只认 RESI5。树模型对
   共线特征只挑主分裂点；KAN 为每个窗口独立学出可读门控形状，重要性摊到家族。
2. **集中度**：LGB gain 集中（top-1 STD30 占 7.3%），KAN 边范数扁平（top-1 仅 1.57%）——参数化
   结构差异，跨模型比排名合理、比份额需谨慎。
3. **LGB 独有**：STD30/KSFT/IMXD5 等，树擅长少数高信息量切点（重尾形态量尤甚）；KAN 受 ±3 截断
   与样条平滑影响未将其排进 top-20，但整体 RankIC 反超（0.0264 vs 0.0152）——两模型在互补
   特征集上各有优势。
4. **一致处**：7 个交集因子是两种参数化收敛到的同一批核心量价信号，与 B1 分层回测稳健层同源。

## 4. 跨 seed 形状稳定性（B14 增补）

对 B7 multi-seed 的 `kan-baseline` 5 个 seed（s42–s46，与 B1 同架构的 CPU 重训版）复刻 B4
口径逐 seed 提取最强边、形状分类与符号 snap。完整表格、事前判定规则与排查：
`results/B14_seed_stability.md`。

**按事前判定规则的结论为「不一致」**（top-12 两两最少重叠 7/12 < 8；细粒度形状标签跨 seed
一致率 0/10）。但呈现清晰的三层结构：

| 层面 | 结果 |
|------|------|
| 曲线 | 同一因子的最强边响应曲线跨 seed 唯一，\|corr\| 最小 0.88、均值 ≥ 0.96，至多整体镜像（φ→−φ 配第二层权重变号，属 KAN 规范对称性） |
| 名单 | 10 个因子在 ≥3/5 个 seed 进入 top-12（RESI5、RESI30、RESI60、RESI20、CORD30 为 5/5 全勤）；尾部 2–4 位轮换 |
| 命名 | 形状标签（U/倒 U、inc/dec）与 snap 函数族不稳定：原始 best_cand 全员同族 0/10，按本报告自带的等价族归并后 plurality 均值 0.66 |

因此本报告的形状读法应落在**因子级响应曲线**这一层：可以写「每个核心量价因子存在一条跨
seed 稳定复现的非线性响应曲线」；具体方向、形状标签与函数名则属**主模型的具体读法**。

口径限制：multi-seed 为 CPU 训练（B7 统一码路径），B1 主 KAN 为 GPU 运行，对比对象是 CPU
同码路径版本；镜像方向由第二层吸收属对称性推断，未做第二层权重符号核对。

## 5. 符号蒸馏验证（B15 增补）

把 158 个特征各自的最强边公式（§2 的 snap 结果，冻结不再训练）替换 KAN 第一层，只重训
第二层（24→1），检验这些可读公式承载了多少模型信息。paired 对照为同脚本、同 seed、同训练
路径的原 KAN，唯一差异是第一层是否冻结为公式。完整口径与逐项对比：
`results/B15_symbolic_distill.md`。

| 口径 | 蒸馏（158 公式冻结） | 对照（样条可训） | 保留 |
|------|---------------------|-----------------|------|
| test RankIC | 0.025696 | 0.026425 | **97.2%** |
| test IC（Pearson） | 0.013515 | 0.019774 | 68.3% |
| 可训练参数 | 240 | 38,160 | — |
| 净值 CAGR（`account`，单区间） | 13.59% | 7.15% | — |
| 10 组单调性 / long_short 日均 | 0.782 / 0.000618 | 0.952 / 0.001168 | — |

读法必须分层：**RankIC 层几乎无损**（公式化保留了两两秩序）；**IC 层损失明显**（预测幅度被
压缩，预测 std −40%）；**头部（topk=30）组合指标在本区间蒸馏占优，而全截面排序区分度对照
更强**。不得笼统表述为「蒸馏优于原模型」或「公式化无损」。全部差异为单一 test 区间
（2023-01-03 ~ 2026-07-23）单 seed 观测。
